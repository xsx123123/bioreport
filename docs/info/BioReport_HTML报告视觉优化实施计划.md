## 二、根因分析（编码 Agent 诊断锚点）

1. **H1 导航栏**：Quarto 默认 Bootstrap5 导航 `container-fluid` 全宽 + `navbar-expand-lg`，
   菜单项靠 `margin` 分散。宽屏（>2000px）下被拉散。→ 用自定义 SCSS 约束容器宽度并紧凑排列。
2. **H2 图表溢出**：plotly 输出固定 width，或 Quarto figure 容器未限宽；双栏布局中
   子项默认 `min-width: auto` 导致 grid/flex 溢出。→ chunk 级 `out-width: 100%` +
   plotly responsive + CSS `max-width: 100%` + `min-width: 0`。
3. **H3 关于页导航**：大概率是 about 页用了不同 layout/title-block，或页面顶部有自定义
   include（`_header.html` / title-block-banner）把 fixed/sticky 导航顶错位；也可能是
   scrollspy offset 问题。→ 阶段 0 只读诊断，先定位再改。

## 三、分阶段实施

### 阶段 0：只读诊断（不改动任何代码）

**目的**：确认主题文件结构、定位 H3 根因、确认 plotly 图生成方式。

**交付**：诊断报告，含——
- 自定义 SCSS 主题文件路径与结构（`theme.scss` / `_quarto.yml` 的 format/theme 配置）
- 关于页生成后的 `<nav>` HTML 与主页对比差异（为何顶部不完整）
- 分析结果节图表的生成代码位置（固定 width 写在哪）
- 项目总览卡片的 HTML 结构（手写 div 还是组件）

### 阶段 1：全局框架修复（导航栏 + 容器宽度 + 标题比例）

改动点：
1. **导航栏**：`.navbar > .container-fluid { max-width: 1200px; margin: 0 auto; }`；
   菜单项左对齐紧跟 logo（`me-auto`），项间距 `1.5rem`；`navbar` 上下 padding
   降至 `0.5rem`；字号 `0.95rem`；当前激活项样式统一（2px 下划线或 pill，全站一致）。
2. **内容容器**：正文 prose 限宽 `max-width: 46em`（约 720-760px）；图表容器可放宽到
   `min(100%, 1000px)` 居中——图可以比字宽，但不能比容器宽。
3. **标题比例**：SCSS 收敛标题尺寸——H1 `1.9rem` / H2 `1.5rem` / H3 `1.25rem`，
   字重 600；表格 caption 统一 `0.9rem` 灰色。

### 阶段 2：项目总览卡片 + 样本信息页

1. **卡片重构**：CSS Grid `grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`，
   `grid-auto-rows: 1fr`（等高）；卡内三段固定结构：标签（0.8rem 灰）/ 数字（2rem、
   字重 700、`font-variant-numeric: tabular-nums`、与正文同字体族）/ 注释（0.8rem）；
   彩色左边条统一 `border-left: 4px solid`，高度 100%；卡片 padding `1.25rem`、
   圆角 `8px`、1px 浅边框。
2. **样本信息导读**（文案成稿，直接可用）：

> 本节列出全部 6 个样本的测序数据量与核心质控指标。其中 Q30 为碱基测序质量值
> ≥30 的比例（本次平均 95.9%，数据质量优秀）；比对率（Mapping Rate）反映 clean
> reads 成功比对到参考基因组 GRCm39 的比例。各样本指标整体均衡，无明显离群样本，
> 详细质量评估请见「质量控制」章节。

3. "表格列名说明"折叠块保留，但样式弱化（去掉抢眼的蓝色左边条，改为普通折叠提示）。

### 阶段 3：分析结果节图文布局

1. 所有 figure chunk 统一加 `#| out-width: 100%`（plotly 渲染配置
   `{'responsive': True}`，不传固定 width）。
2. 自定义 CSS：`.quarto-figure img, .plotly-graph-div { max-width: 100%; height: auto; }`；
   双栏 PCA 图的容器子项显式 `min-width: 0`。
3. 图文比例：正文限宽 46em；双图两栏布局保留，但每栏 `max-width: 480px` 居中，
   图题（caption）字号 0.85rem 灰色，置于图下方。

### 阶段 4：关于页文字优化

1. **正文行宽**：prose `max-width: 46em`（随阶段 1 全局生效，此页验证）。
2. **加粗规则**：每段加粗 ≤ 2 处，只保留术语/产品名首次出现（BioReport、CygnusX
   BioOps 保留；成句加粗一律取消）。
3. **引用块改造**：去掉粗黑左边条；改为——无边框、浅灰底 `#f8f9fa`、圆角 8px、
   padding 1.5rem；英文 "We are made of star-stuff." 斜体 1.1rem 置底作为落款，
   中文「从星尘出发，向科学发现不断探索。」作为主句 1.25rem 常规体；大写英文
   "FROM STARDUST, TO DISCOVERY" 降为 0.8rem 字距拉宽的装饰小标题（letter-spacing
   0.15em，灰色），或直接移除。
4. **标题与分割线**：去掉标题下方的 hr（保留标题本身样式即可），节间距用
   `margin-top: 3rem` 控制节奏。
5. **中英混排标题**：统一为「中文（English）」格式（现有格式保留，只统一字号字重）。
