# BioReport 报告页 UI 优化实施手册

- 版本：v1.0（2026-10-20）
- 性质：活文档。同一主题后续迭代追加新 Part，不另起文档。
- 姊妹文档：《BioReport双语HTML性能优化实施手册.md》（性能主题，独立推进，无依赖冲突；注意两份手册都会碰 `bioreport/i18n.py` 外壳与模板样式，施工时分开 commit）。
- 施工方式：第 2 节的提示词整段粘贴给编码 Agent；验收权在用户手里。

## 2. 提示词 P-UI（整段粘贴给编码 Agent）

```text
你是一名资深前端工程师。项目是基于 Python + Quarto 的生信报告生成引擎 BioReport，
报告样式来自 Quarto 模板与自定义 SCSS/CSS（templates/ 目录、bioreport/renderer.py、
bioreport/i18n.py 外壳脚本及相关样式文件）。

任务：在现有报告页面基础上做 UI 细节优化。先阅读现有模板与样式代码，理解当前实现后
再修改。禁止推倒重写，禁止改动报告内容、章节结构、分析逻辑与导航路由，禁止引入新
依赖（确有必要先说明理由）。所有改动同时作用于中文与英文版本，亮/暗两种模式都要验证。

## 需要修改的问题（逐条执行）

1. 语言切换按钮改为分段控件：当前「中文 / English」并列显示，无法识别当前语言。
   改为 segmented control：容器为 pill（高 36px，圆角 18px，背景 #f1f5f9，内边距
   3px）；内部两段「中文」「EN」，当前语言段背景用品牌主色（沿用导航链接的蓝色，
   从现有 CSS 变量取，不要新造色值）、文字 #fff、圆角 15px；非当前段文字 #64748b。
   点击非当前段触发切换，段间过渡 transition 200ms ease。加 aria-pressed 状态。
2. 深色模式按钮补全状态与反馈：与语言控件同高（36×36px），统一为无边框或
   1px solid #e2e8f0 的圆形/圆角方形按钮。亮模式显示 moon 图标、暗模式显示 sun
   图标，切换时图标 200ms 旋转淡入过渡；加 tooltip（亮模式显示「切换到深色模式」，
   暗模式显示「切换到浅色模式」，英文版对应英文文案）与 aria-label。初始主题尊重
   prefers-color-scheme，用户手动选择后记住选择（单文件场景用内存态即可，不要求
   持久化）。另外检查：切换深色后 Plotly 图表与表格是否跟随——若现有实现不跟随，
   本次只保证页面框架与文字正确换色，图表联动列为已知限制写在输出里，不要硬改。
3. 统一右上角控件组：语言切换、深色模式两个控件组成一个控件组（间距 8px，垂直
   居中对齐）；「关于」从控件组中移出——它本质是导航项，并入顶部导航链接序列末尾，
   样式与其他导航链接一致；校徽与控件组之间加 12px 间距或 1px 分隔线（#e2e8f0，
   高 20px）。组内不再出现第三种按钮风格。
4. 表格可用性：样本信息等 DataTables 表格——表头列被截断时给表格容器加横向滚动
   提示（右侧渐隐阴影，滚动到底消失）；消除 Search 框与表体之间的大片空白（检查
   itables 包裹层的 margin/min-height，压到 16px 以内）；Copy/CSV/Excel 按钮改为
   统一的现代按钮（高 32px、圆角 6px、1px 边框 #e2e8f0、hover 背景 #f1f5f9、
   图标用内联 SVG 替换 emoji）。
5. 标题体系统一：中文页面内的英文标题（如「RNA-seq Result」）译为中文；小节标题
   的英文括号注释规则统一——全部保留或全部去掉，建议保留但统一格式为「中文标题
  （English）」；拉开标题层级：H1 32px/700、H2 24px/600、H3 18px/600，行高 1.4，
   以现有字号为基准就近调整，不要大幅改动版心宽度。
6. 侧栏目录激活：左侧「Contents」改为随页面语言显示「本页目录 / Contents」；
   列出当前章节的小节锚点链接（点击平滑滚动，scroll-behavior: smooth，尊重
   prefers-reduced-motion）；当前可视小节高亮（品牌蓝色，左边框 2px 指示）。
7. 看板娘技术问题排查：查明角色下方灰色小 pill 的来源（疑似残留/折叠元素），
   确认无用则移除；角色本体保留，但加一个配置项（如 report.mascot: true/false）
   控制是否渲染，默认 true；检查其在 1366px 宽度下不遮挡正文与表格横向滚动条，
   遮挡则右移或缩小（宽度不超过 120px）。

## 全局约束

- 整体风格与现有报告一致：白底、品牌蓝导航、卡片式布局；这不是重新设计。
- 所有颜色优先引用现有 CSS 变量/SCSS 变量，不新增近似色值。
- 动效只用 transform/opacity，时长 200~300ms，尊重 prefers-reduced-motion。
- 中英文两版、亮暗两模式、桌面 1366px 与 2560px 两档宽度都要验证无布局破损。
- 与性能优化并行的另一份实施手册也在改外壳与模板：本次改动独立 commit，
  不触碰 i18n.py 的解压/缓存逻辑。

## 验收标准（逐条自检）

- [ ] 7 个问题逐条有对应改动，提供改前/改后截图对照
- [ ] 语言切换控件能一眼看出当前语言；深色按钮图标随状态变化且有 tooltip
- [ ] 表格无截断歧义、无大片空白、按钮风格统一
- [ ] 中英文两版标题规则一致，无遗留英文标题（页面语言不匹配）
- [ ] 报告内容、图表、表格功能与改前完全一致

完成后简述：每个问题对应的修改文件与关键属性改动。
```

## 3. 验收 checklist（用户手测）

| 操作 | 期望现象 | 不通过时的处理 |
| --- | --- | --- |
